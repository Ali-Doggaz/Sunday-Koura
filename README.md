# Sunday Koura ⚽

Inscriptions aux matchs de foot du dimanche: one tap to join, a waiting list, and admins who manage everything.

- **Stack**: Next.js 16 (App Router, Server Actions) · Better Auth (Google, Facebook) · Drizzle + Postgres · Tailwind/shadcn
- **Hosting**: Vercel (Hobby) + Neon (Free). Both are free and sleep when idle. See [DEPLOY.md](DEPLOY.md).
- **Spec**: [SPEC.md](SPEC.md)

## Local development

```bash
mise install                # Node 24
npm install
cp .env.example .env.local  # then set BETTER_AUTH_SECRET; E2E_TEST_LOGIN=true for a fake sign-in
npm run db:up               # Postgres in Docker on port 5433
npm run db:migrate
npm run dev                 # http://localhost:3000
```

Without OAuth keys, set `E2E_TEST_LOGIN=true` in `.env.local` and sign in with any name. Put `<name>@test.local` in `ADMIN_EMAILS` to be admin.

## Checks

```bash
npm run typecheck && npm run lint
npm test            # unit + DB integration tests (test database, Docker must run)
npm run test:e2e    # Playwright, against a production build
```

## Code map

| Path | What |
|---|---|
| `src/lib/games/rules.ts` | Pure game rules: limits, waiting list, promotion |
| `src/lib/games/service.ts` | All game changes, each in a transaction that locks the game row |
| `src/lib/games/queries.ts` | Read models for the pages |
| `src/lib/actions/` | Server Actions (re-check the session, then call the service) |
| `src/lib/auth.ts` | Better Auth: providers, admin plugin, first admins from `ADMIN_EMAILS` |
| `src/db/` | Drizzle schema (`auth-schema.ts` is generated by `npx auth generate`) |

Schema change: edit `src/db/schema.ts`, then run `npm run db:generate` and `npm run db:migrate`.
